# Snapshots Directory

This directory is for storing screenshots and visual materials related to LeetCode problems.

## Directory Structure

Organize snapshots by problem name:

```
snapshots/
├── find-the-difference/
│   ├── problem.png
│   ├── example.png
│   └── result.png
├── merge-strings-alternately/
│   ├── problem.png
│   └── example.png
├── move-zeroes/
│   ├── problem.png
│   └── example.png
└── README.md (this file)
```

## Snapshot Types

### problem.png
Screenshot of the complete problem statement from LeetCode

### example.png
Screenshot showing example test cases and expected outputs

### result.png (optional)
Screenshot of successful submission or execution results

## Adding New Snapshots

1. Create a new subdirectory with the problem name in kebab-case
2. Add your screenshots following the naming convention above
3. Reference them in the main README.md if needed

## Image Guidelines

- Use PNG format for better quality
- Keep file sizes reasonable (compress if needed)
- Ensure screenshots are clear and readable
- Include the full problem statement when possible
